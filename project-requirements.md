During the coding phase, all descriptions defined in the diagrams must be strictly respected (mandatory).

The SOLID principles must be correctly applied, especially Single Responsibility (S) and Open/Closed (O), which are mandatory.

From the Object-Oriented Programming (OOP) principles, the project must include at least:

abstraction

inheritance

polymorphism

method overloading

method overriding

Several interfaces must be created and implemented by classes.

After the project presentation, the system’s capability must be demonstrated by applying the Open/Closed (O) principle of SOLID.

For preparing the diagrams, a UML modeling tool must be used.

Everything must be included in the project documentation, while the source code must be provided as a separate file.
